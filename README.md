# Adactin Hotel Reservation Automation Framework

## Project Overview
This project automates the Adactin Hotel Reservation System using Selenium WebDriver and Cucumber BDD.

## Tech Stack
- Java
- Selenium WebDriver
- Cucumber BDD
- Maven
- Page Object Model (POM)
- Extent Reports

## Features Automated
- User Registration
- Login
- Search Hotel
- Select Hotel
- Book Hotel
- Logout

## Framework Features
- PageFactory Design Pattern
- Cross Browser Support
- Explicit Wait
- Config Reader
- Screenshot Capture
- Extent Reporting

## Execution
Run using:

mvn test
